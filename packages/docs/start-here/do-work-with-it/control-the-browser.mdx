---
title: "Control the browser"
description: "How to use VenomCowork to automate the built-in browser"
---

Computer-use in VenomCowork currently works through the built-in VenomCowork Browser. It does not yet mean full desktop control of Ubuntu, macOS, or Windows apps.

VenomCowork can open pages, click, fill forms, read page content, and take screenshots inside that browser. If you connect to a remote VenomCowork server, the browser runs on that remote worker.

Today, the supported path is the first-party `VenomCowork Browser` extension.

## Requirements

- Use the desktop app or a remote worker that exposes the VenomCowork Browser.
- Keep `VenomCowork Browser` enabled in `Settings > Extensions`.

Then go back to the session view and ask VenomCowork to open a website.
